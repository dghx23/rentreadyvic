Configuration notes
Current public defaults were set from the official Victorian RentAssist and Services Australia rules checked in September 2026. Updating these values here changes the browser prototype on this origin. Production should persist the same configuration server-side with audit history and effective dates.
Official RentAssist income/asset limits currently used by the prototype are effective from 28 May 2026; bedroom-based maximum loan amounts are effective from 1 October 2025.
