What each tool does

Every tool answers a specific question.

The point is not just to return a number. Each tool is designed to explain the inputs, the result and what changed when you adjust a figure.

01

Property listing & shortlist

Start with the property so the rest of RentReady knows which rent and bond you are working with.

  • Paste a rental advertisement.
  • Extract address, weekly rent, bond, availability and other recognised details.
  • Review the important information from the listing.
  • Add more properties and move between a shortlist.
  • Use the selected property's rent in affordability and eligibility tools.
Add or compare properties → 02

Income support & working more

See work income and income-support payments together instead of looking at them separately.

  • Identify whether you receive income support.
  • Select configured payments such as JobSeeker, DSP and Rent Assistance.
  • Enter earnings and adjust them with sliders.
  • Apply configured free areas, tapers and payment reductions.
  • See the combined result as work income changes.
Open income calculator → 03

Break-even chart

Visualise the relationship between earnings, payment reductions and total income.

  • Plot earnings against income-support changes.
  • Show where configured taper rules change.
  • See sections where total income rises, flattens or changes more slowly.
  • Use the graph alongside the same figures in the income calculator.
View the chart → 04

Rent affordability

Put the selected property's rent beside the income figures you have already entered.

  • Reuse weekly rent from the active shortlist property.
  • Compare rent with your saved income.
  • Calculate rent as a percentage of income.
  • Adjust the affordability threshold you want to examine.
  • Compare properties without rebuilding the calculation.
Check affordability → 05

RentAssist bond-loan eligibility

Work through the eligibility tests together and see which test changes the result.

  • Use household and property information.
  • Test configured income limits.
  • Test configured asset limits.
  • Use the rent/property figures already saved.
  • Show each check separately so a failed test is understandable.
Check RentAssist → 06

Form 3 & Form 3A guide

  • Explain Form 3 and Form 3A in context.
  • Guide the applicant through the information collected.
  • Explain protected attributes and discrimination issues where relevant.
  • Track progress through the application.
  • Reuse applicant, employment and property details where the prototype supports it.

How the calculator works

Change one figure and see the whole picture move.

The money tools are designed to make the interaction between work, payments and rent visible.

What you put in

Your saved profile provides the shared inputs used across the calculators.

✓
Work income — change earnings to test different hours or wages.
✓
Income-support payment — choose the payment variables that apply to you.
✓
Property rent — pull the figure from the property you selected in your shortlist.
✓
Household / assets — use these where an eligibility test needs them.
WeeklyFortnightlyMonthlyYearly
1. Convert the display period

The same underlying values can be shown weekly, fortnightly or monthly. Yearly remains available but is intentionally less prominent.

2. Apply the configured payment rules

The income calculator uses the current configured free areas, taper rates, maximum payment amounts and related variables in the prototype.

3. Combine work + payment

Instead of only showing “Centrelink goes down”, RentReady shows the payment alongside earnings so you can see the combined result.

4. Feed the result into renting tools

The same income and selected-property information can then be used for affordability and eligibility checks.

References

A reference workflow, not just two empty boxes.

RentReady explains what the reference is for, helps prepare the request and turns the response into a structured record.

What the References tool explains

The dedicated References section explains the reference requirement in the context of the rental application, what information the prototype asks the referee for, and how the response becomes part of your saved application material.

1
Enter referee details

Name, relationship and email are used to build the request.

2
Generate the questions

RentReady creates a structured email with prompts the referee can answer directly.

3
Capture the reply

The prototype can parse a pasted response into structured answers.

4
Create a printable record

The formatted result can currently be printed or saved as PDF from the browser.

Prototype status: outbound email currently opens the user's mail client and inbound replies are pasted manually. Automatic send/receive and cryptographic signing still require the backend connection described in the project.
